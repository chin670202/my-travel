## 🧭 排程原則（本版依此重排）

1. **每日景點上限 3 個**（不含餐飲、順路快閃停靠、休閒散步）。
2. **不走回頭路**：全程順時針單向前進，每天的點依「當日行進方向」由前往後排；**跨縣市的點一律放在移動日的路上**，不放在定點日。
3. **11:00–15:00 盡量室內或有遮蔭**（8 月最熱時段），戶外海邊/步道排在上午或 16:00 後。
4. **顧 8 歲體力**：步行多的點一天最多一個，其餘以「下車即到」為主。
5. 時段以 **上午 / 午後 / 傍晚** 標示；⚠️ **各段車程尚未逐段查證**，出發前需用 Google Maps 實查（本表不寫未經查證的分鐘數）。
